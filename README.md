# Genius Work SaaS

Une application de gestion des présences de nouvelle génération, conçue pour simplifier et moderniser la gestion des ressources humaines.

## 🌟 Caractéristiques Principales

- **Gestion Multi-Méthodes de Pointage**
  - Badge Card QR Code
  - Biométrie / RFID
  - Mobile Pointage avec Option Tracking

- **Gestion Complète des RH**
  - Suivi des présences et absences
  - Gestion des congés
  - Rapports et analytics en temps réel
  - Notifications automatiques

- **Interface Moderne et Intuitive**
  - Dashboard personnalisable
  - Application mobile pour les employés
  - Interface d'administration complète

## 🛠 Technologies Utilisées

- **Frontend**: Filament (basé sur Tailwind CSS)
- **Backend**: Laravel (PHP)
- **Base de Données**: MySQL
- **Application Mobile**: Flutter
